看教程习惯一点五倍，换一个网站想用两倍。每次都重新找倍速菜单，这个小动作就会不断重复。

“三人聚智 · 视频倍速”是一款独立浏览器扩展。它把设置分成全局默认和站点专属两层：先设日常速度，再让常用网站各记各的习惯。

这次用Mac上的Chrome 157和扩展1.0.1进行真实操作。B站设置1.5×、腾讯视频设置2×；保存后读取媒体元素的实际倍速，并检查播放状态。下面讲的是本次实测结果，不把一个页面成功写成所有网站通用。

![](https://xz.sanrenjz.com/image/%E8%A7%86%E9%A2%91%E5%B0%81%E9%9D%A2_16%E6%AF%949.png?imageSlim)

## 从浏览器工具栏打开

先解压安装包，在Chrome地址栏输入 chrome://extensions，打开开发者模式，点击“加载未打包的扩展程序”，选择包含 manifest.json 的 extension 文件夹。

加载后，打开浏览器的扩展菜单，点击插件旁的固定按钮。图标留在工具栏，进入视频网页后直接点击它，就能打开真实设置弹窗。安装之前已经打开的视频页面，请先刷新一次。

![](https://xz.sanrenjz.com/image/%E6%BC%94%E7%A4%BA%E6%88%AA%E5%9B%BE-%E6%B5%8F%E8%A7%88%E5%99%A8%E5%85%A5%E5%8F%A3.png?imageSlim)

本教程使用开发者加载方式；没有将送审或提交状态写成已经在商店上架。

## 先设一个全局默认值

在“全局默认倍速”中输入1.25，再点击“保存”。没有专属规则的网站就使用这个值。本次移除B站的站点规则后，媒体元素实际返回1.25，且处于播放状态。

全局值适合做日常默认。为某个网站单独保存规则后，站点设置会优先生效。

## B站1.5倍，腾讯视频2倍

在B站视频页点开扩展，点击1.5×即可自动保存，不必再点保存按钮。切换到腾讯视频的公开视频页，再选择2×。

需要更细的数值时，可输入0.25到4之间的速度，再点击“保存到此站点”。设置前看清弹窗中的当前域名，避免存到别的网站。

![](https://xz.sanrenjz.com/image/%E6%BC%94%E7%A4%BA%E6%88%AA%E5%9B%BE-B%E7%AB%99%E5%AE%9E%E6%B5%8B.png?imageSlim)

图中为最终视频的B站实际画面；腾讯视频2倍的设置和播放过程见配套视频。校验时还读取了播放器媒体元素，不能只把弹窗显示的目标值当作实际播放结果。

| 本次操作 | 实际结果 |
| --- | --- |
| B站保存专属规则 | 1.5× |
| B站切换到另一条视频 | 1.5×，媒体正在播放 |
| B站刷新后重新检查 | 1.5×，媒体正在播放 |
| 腾讯视频公开短视频 | 2×，媒体正在播放 |
| 腾讯视频刷新后检查 | 2×，媒体正在播放 |
| 移除B站规则，跟随全局 | 1.25×，媒体正在播放 |

## 规则多了，集中管理

展开“站点倍速”，可以统一查看、添加和删除。演示中新增了example.com规则，随后删除，保留B站1.5×和腾讯视频2×。

子域名可以继承父域名规则；如果有更具体的子域名规则，就优先使用它。内嵌播放器按顶层网页的站点匹配，不由视频CDN域名决定速度。

“恢复跟随全局倍速”会移除当前匹配的规则。如果还存在父域规则，仍会继续继承，需要一并检查。

## 临时暂停，不用删设置

右上角开关用于暂停和恢复。关闭后，当前受控媒体恢复1×，已有设置保留；重新开启，再应用保存的规则。本次在B站检查了媒体的实际读数，暂停为1，恢复后为1.5。

扩展启用时会维持所设速度。如果想临时使用播放器自己的倍速菜单，可以先暂停扩展。

## 配置留在本机

启用状态、全局默认和站点规则保存在本机。扩展在本机读取网页域名来匹配规则，不上传这些配置，也不做跨设备同步。

![](https://xz.sanrenjz.com/image/%E6%B5%81%E7%A8%8B%E5%9B%BE-%E6%93%8D%E4%BD%9C%E5%9B%9E%E9%A1%BE.png?imageSlim)

先设全局，再设站点，最后刷新检查实际结果。从最常看的两个网站开始配置，就能建立自己的播放习惯。
