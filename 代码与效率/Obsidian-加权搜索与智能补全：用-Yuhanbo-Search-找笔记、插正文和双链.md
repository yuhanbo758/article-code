Yuhanbo Search 是一款 Obsidian 社区插件，提供按字段设置权重的笔记搜索，也能直接在编辑器里插入正文、标题双链和块链接。下面用写项目复盘的场景演示这两项功能，再实测文件夹范围和搜索权重如何改变结果。

![](https://xz.sanrenjz.com/image/%E8%A7%86%E9%A2%91%E5%B0%81%E9%9D%A2_16%E6%AF%949_Obsidian%20%E5%8A%A0%E6%9D%83%E6%90%9C%E7%B4%A2.png?imageSlim)

## 1. 在 Obsidian 里安装并打开插件

1. 打开 设置 → 第三方插件 → 浏览，搜索 Yuhanbo Search，打开详情后点击 安装 → 启用。 [Obsidian 社区插件页](https://community.obsidian.md/plugins/yuhanbo-search)
1. 回到要编辑的笔记，按 Ctrl+P 打开命令面板，输入 打开加权搜索，选择 Yuhanbo Search：打开加权搜索。也可以点击左侧功能栏上提示为 自定义加权搜索 的放大镜。
1. 常用的话，可以在 设置 → 快捷键 搜索同一条命令，再绑定一个组合键。插件默认没有预设快捷键。
![](https://xz.sanrenjz.com/image/%E5%85%A5%E5%8F%A3-%E5%91%BD%E4%BB%A4%E9%9D%A2%E6%9D%BF.png?imageSlim)

如果社区市场的下载暂时不可用，可从同一版本的 GitHub Release 下载 main.js、manifest.json 和 styles.css，放到目标笔记库的 .obsidian/plugins/yuhanbo-search/。重新打开笔记库后，到第三方插件列表启用。 [GitHub Releases](https://github.com/yuhanbo758/obsidian-yuhanbo-search/releases)

## 2. 按字段搜索，打开命中的笔记

在搜索框输入至少两个字符。窗口上方可以切换 文件名、目录、标签、标题、内容、引用。比如在复盘草稿里搜索「发布复盘」，先命中文件名。再点亮 内容，正文里包含这几个字的「交付清单」也出现在结果里。结果卡片会列出匹配的字段和得分，点击文件就能打开原文。

![](https://xz.sanrenjz.com/image/%E7%BB%93%E6%9E%9C-%E5%AD%97%E6%AE%B5%E6%90%9C%E7%B4%A2.png?imageSlim)

得分受各字段权重和匹配次数影响。想先找到标题明显的文档，可以提高 文件名权重 或 标题权重。查只记得半句话的资料时，可以开启 内容，再按需要调整 内容权重。3.0.6 的搜索窗口默认打开文件名、目录、标签和标题，按需开启内容和引用。结果较多时可以点击底部的 加载更多结果。

## 3. 一个 @ 会做什么？三种补全怎么输入？

在笔记正文的编辑模式操作，确保 设置 → Yuhanbo Search → 启用智能补全 已打开。符号用半角，但关键词可以是中文。单个 @ 属于普通文字，本插件从连续两个 @ 开始识别前缀。只输入前缀时，需要继续输入达到最少长度的关键词，才能查到候选。

| 笔记里输入 | 选中后写入 | 适用情况 |
| --- | --- | --- |
| @检查清单 | 仍是原样文字 | 单个 @ 不触发 Yuhanbo Search |
| @@检查清单 | 检查清单：核对标题、素材、链接和发布日期。 | 搜笔记正文并插入匹配的一行 |
| @@# 发布结论 | [[发布复盘#发布结论\|发布结论]] | 搜 Markdown 标题，插入定位到标题的双链 |
| @@@ 核对材料 | 指向 原始记录#^ACME42-4 的块链接 | 搜匹配的文本块，插入可定位到源段落的链接 |在 @@# 或 @@@ 后加一个半角空格。实录对照过 @@#发布结论 和 @@@核对材料，漏掉空格时没有候选。补上后，候选会同时列出匹配内容和出处。用 ↑、↓ 选择，按 Enter 或点击候选插入，Esc 关闭候选。默认至少 2 个中文字或 4 个英文字母，关键词达标后才查询。

在阅读视图点击标题双链，实录跳到「发布复盘」的「发布结论」。块链接定位的前提是源段落已经有同一个块标识，演示里的源段落提前写入了 ^ACME42-4。如果只打开文件却没定位到段落，检查链接中 #^ 后的标识与源段落是否一致。普通正文补全写入的是文本，之后编辑原笔记时，已插入的文字需要自行更新。

## 4. 智能补全设置

实录先输入 @@共用模板，候选有两条。进入 设置 → Yuhanbo Search → 智能补全搜索文件夹 填入 演示资料，回到草稿重试，候选只剩资料目录里的那条。

## 5. 九项搜索权重与排序

每项可从 1 调到 10。得分按照匹配字段和命中情况累加。

| 字段 | 3.0.6 默认权重 |
| --- | --- |
| 文件名、目录、标签 | 10、9、8 |
| 一级、二级、三级、四级及以下标题 | 7、6、5、4 |
| 正文、引用 | 3、2 |搜索窗口上方的按钮决定本次查哪些字段。查正文或 Markdown 引用时，要启用 内容 或 引用。这些权重用于加权搜索结果。

1. 搜索「发布复盘」，点亮 内容。测试库里，「发布复盘」通过文件名命中得 10 分，「交付清单」通过正文命中得 3 分。
1. 打开 设置 → Yuhanbo Search → 搜索权重，将 文件名权重 从 10 拉到 1，保留 正文内容权重。
1. 关闭设置，重新打开加权搜索，执行同一个查询并点亮 内容。「发布复盘」变为 1 分，「交付清单」升到第一条。
## 6. 排除文件夹与索引维护

| 设置 | 3.0.6 默认值 | 用法 |
| --- | --- | --- |
| 排除的文件夹 | 留空 | 排除相对于库根目录的路径，多个路径用半角逗号分隔。加权搜索索引及补全都跳过这些目录 |
| 缓存更新间隔（分钟） | 60 | 自动更新开启时，每隔多少分钟重建索引 |
| 自动更新缓存 | 开启 | 运行定时更新。改动开关或间隔后，重新加载插件可让定时安排使用新值 |
| 手动更新索引 | 「更新索引」按钮 | 改动笔记或排除范围后，如果要马上刷新，可点击并等待「搜索索引已更新」 |实录先查「索引演示标记」，得到一条结果。随后在设置底部的 排除的文件夹 填入 排除演示 并点击 更新索引。完成后重搜同一个词，窗口显示「没有找到匹配的结果」。
