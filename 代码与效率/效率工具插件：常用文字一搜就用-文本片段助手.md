# 别再翻聊天记录：把常用回复、提示词和代码变成随手可用的片段

![](https://xz.sanrenjz.com/image/%E6%96%87%E6%9C%AC%E7%89%87%E6%AE%B5%E5%8A%A9%E6%89%8B-%E5%B8%B8%E7%94%A8%E6%96%87%E5%AD%97%E4%B8%80%E6%90%9C%E5%B0%B1%E7%94%A8-%E5%B0%81%E9%9D%A216%E6%AF%949-20261003.png?imageSlim)

你有没有这样的经历：客户问了一个熟悉的问题，明明以前回复过，却要重新翻聊天记录；写周报时，又得找上一周的文档；想让 AI 帮忙整理内容，却忘了那段已经调整过很多次的提示词放在哪里。

这些工作单次并不复杂，麻烦在于每天都重复发生。与其反复寻找，不如把值得复用的文字提前整理好。

余汉波文本片段助手是三人聚智效率工具中的一个插件。它把本地 Markdown 文件变成可搜索、可预览、可收藏的文字片段库，并接入主程序的快速调用。常用回复、工作模板、AI 提示词和代码片段，都可以放在同一个入口里管理。

管理界面的全貌如下：顶部提供新建、剪贴板导入、设置和刷新；中间可以搜索、排序、收藏、查看最近使用和按目录筛选；每条片段旁边可以复制或编辑。

## 先理解它能帮你做什么

它适合保存已经写好、需要反复使用的文字。比如客户咨询回复、会议纪要结构、周报模板、写作提示词、常用命令或代码示例。

| 使用场景 | 建议保存的片段 | 使用时的动作 |
| --- | --- | --- |
| 客户沟通 | 需求确认、进度说明、资料收集清单 | 搜索关键词，复制或插入，再补充具体信息 |
| 日常办公 | 周报、会议纪要、邮件结构 | 调用模板，填写本次工作的内容 |
| AI 与开发 | 调整好的提示词、命令、代码示例 | 找到片段，放入目标工具，按需要修改 |保存 AI 提示词只是文字复用，本插件不会替你调用 AI；保存代码片段也不会自动执行代码。把它当成自己的常用文字工具箱，就容易理解它的价值。

## 第一次使用：从主程序打开插件

先启动三人聚智效率工具，在本地插件搜索框中输入“文本片段”，找到“余汉波文本片段助手”，双击插件卡片打开管理界面。

进入插件后，先点击“设置”，为片段选择一个本地文件夹。插件读取的是 .md 文件，每个文件对应一个文字片段。已有 Markdown 模板可以直接作为整理起点，无需把所有文字重新录入。

设置支持多个片段目录，并可以指定默认目录。新建片段会保存到默认目录；已有片段可以按所属文件夹筛选。开启“搜索子文件夹”后，子目录中的 Markdown 片段也会进入扫描范围。

设置窗口中可以添加目录、指定默认目录，并选择是否搜索子文件夹及自动插入：

## 新建片段：把好用的文字留下来

点击“新建片段”，填写标题和正文，保存后就能在列表里找到它。标题应尽量包含以后会搜索的词，例如“客户回复-确认需求”，比“模板一”更容易找回。

如果文字已经在剪贴板里，可以点击“从剪贴板新建”。插件会把当前剪贴板文字带入新建窗口，你补好标题、检查内容后再保存。

例如，可以先建立这样一条客户回复：

```vb.net
标题：客户回复-确认需求

您好，已收到您的需求。
为了便于确认方案，请补充以下信息：
1. 希望实现的具体功能；
2. 当前使用环境或软件版本；
3. 预期完成时间。
收到后，我会进一步整理并回复您。
```

这类片段不需要很长。能够清楚表达一个稳定的工作动作，就值得保存。

## 搜索与预览：找到之后先看清楚

管理界面的搜索框可以同时检索片段标题和正文。输入多个搜索词时，需要全部匹配，适合用“客户 需求”“周报 总结”这样的组合缩小范围。

点击片段可以打开预览，查看完整正文和文件位置；列表上也提供“复制”和“编辑”按钮。预览使用文字方式展示 Markdown 原文，复制时保留原文内容，方便在目标程序里继续编辑。

如果目录中有多个相近模板，可以先预览确认，再复制。这样比单凭标题猜测更稳妥。

## 收藏、最近使用和目录筛选：让常用片段更容易找

点击星号可以收藏一条片段，再通过“收藏”筛选只看常用内容。建议把每天使用的回复和模板放入收藏，把偶尔使用的内容留在全部列表中。

“最近使用”会记录通过复制或调用使用过的片段，适合继续处理同一类工作。列表还支持文件夹筛选，以及名称排序和最近修改排序：按业务分组时使用目录筛选，刚调整过模板时使用最近修改排序。

收藏和最近使用都是辅助查找入口，原始内容仍保存在本地 Markdown 文件里。

## 快速调用：在需要输入的地方使用片段

管理界面用于整理内容，日常输入则可以通过主程序的快速搜索完成。

1. 在目标程序的输入框中放好光标。
1. 按 Alt + Space 呼出主程序快速搜索。
1. 输入片段关键词，找到需要的内容。
1. 使用方向键选择，按 Enter 调用。
启用“自动插入内容”后，选择片段会尝试将文字插入之前的活动窗口；关闭该设置时，则复制到剪贴板，由你切回目标程序手动粘贴。

插件也声明了“片段管理”“片段速查”等超级面板入口。需要在主程序启用超级面板并添加相应动作；具体位置随个人面板配置而定。本次视频实际演示的是 Alt + Space 快速搜索与记事本插入。

## 模板维护：编辑、副本和刷新

已有片段支持编辑标题和正文。修改标题相当于重命名 Markdown 文件；插件会检查同名文件，避免直接覆盖已有内容。

想保留通用模板、再做一个客户或项目专用版本，可以在预览里选择“创建副本”。这比直接改掉原模板更适合有多个使用场景的内容。

如果你在 Obsidian 或其他编辑器里修改了 Markdown 文件，回到插件点击“刷新”，重新读取磁盘内容。插件还会检查编辑或删除前文件是否发生变化，避免在旧内容基础上覆盖外部修改。

需要注意：删除片段会删除对应的本地文件，并非只从列表隐藏。重要模板建议先另存或备份，再确认删除。

| Esc | 插件管理界面：关闭弹窗 |## 从三条片段开始，建立自己的文字工具箱

不必一开始就整理一个庞大的模板库。先保存三条真正会用到的内容：一条常用回复、一份工作模板、一段提示词或代码。给它们起容易搜索的标题，把最高频的内容加入收藏，再实际调用几次。

当一段文字值得再次使用时，就把它留下来；当某个模板不再适用时，就及时调整。片段库会逐渐贴合你的工作，而不是变成另一个难以查找的资料堆。
