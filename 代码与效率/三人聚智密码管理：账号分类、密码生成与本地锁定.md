网站账号、工作邮箱、测试环境密钥，散落在不同笔记里，用时很容易找错。三人聚智里的“密码管理器”，把账号记录、分类、检索和复制放在同一个桌面窗口中，适合整理自己需要反复查用的登录资料。

这篇教程围绕密码管理器，依次介绍首次设置、新建记录、生成密码、分类搜索、导入导出和锁定。示例全部使用虚构账号；照着操作时，可以先建一条测试记录，熟悉界面后再整理自己的资料。

## 从主程序找到密码管理器

先打开三人聚智主程序，选择“效率工具”。在顶部搜索框输入“密码管理”，等列表显示“密码管理器”卡片后，双击卡片主体打开。首次进入会看到“设置开屏密码”界面，之后才在插件窗口里管理记录。视频开头保留了从主程序界面、输入搜索词、双击卡片到插件出现的过程，可跟着画面找到入口。

![](https://xz.sanrenjz.com/image/%E6%BC%94%E7%A4%BA%E6%88%AA%E5%9B%BE-%E4%B8%BB%E7%A8%8B%E5%BA%8F.png?imageSlim)

主程序入口：先搜索插件名称，再打开对应卡片。

## 首次打开，先设置开屏密码

新库第一次打开时，需要设置开屏密码并再次确认。两次输入应一致；界面允许至少四位，但实际使用建议选择更长、独立且能妥善保管的口令。

开屏密码用于进入插件和解锁密码字段。不要把它和某个网站的账号密码混为一谈，也不要随意点击“重置密码”：重置会清空已有账号数据，它不是找回口令的入口。首次设置完成后，才进入账号列表。

## 新建一条账号记录

点击列表顶部的“+”，按需要填写标题、用户名、密码、API 密钥、网址、分类和备注。标题可以写成“演示邮箱”这样容易辨认的名称；网址填写对应服务的登录地址，备注则补充用途或环境。

例如，同一个服务有个人账号和工作账号，可以在标题中区分；开发环境与生产环境也应明确标记。这样搜索结果出现时，就不容易复制错记录。示例里填写的 demo@example.com 仅用于说明字段，不对应真实登录资料。

![](https://xz.sanrenjz.com/image/%E6%BC%94%E7%A4%BA%E6%88%AA%E5%9B%BE-%E8%B4%A6%E5%8F%B7%E8%AF%A6%E6%83%85.png?imageSlim)

账号详情：把标题、用户名、网址和用途写清楚，之后检索更方便。

新建记录时，界面会预先填入一个生成的密码，但这不代表记录已经保存。检查内容后，明确点击“保存”，确认条目出现在列表里。已有记录编辑后有自动保存逻辑，首次新增仍应按按钮完成保存，避免把输入中的草稿当成入库结果。

## 按需生成密码，再保存到记录

在密码生成器中，可以调整长度，以及数字、大写字母、小写字母和符号的组合。先根据目标网站的规则选择字符，再点击“使用此密码”，将结果带回当前记录；最后检查并保存。

界面提供的是字符和长度选择，并不保证每个网站都接受。部分网站限制符号或长度，遇到这类情况应按其规则调整。本插件当前生成逻辑使用 Math.random()，不要把它当作密码学强随机生成器；高价值账号仍应采用符合自身安全要求的口令方案。

API 密钥字段用于保存你从服务商处取得的密钥，插件不会替你向服务商申请或生成可用 API 密钥。

## 分类、搜索和复制怎么配合

记录多起来后，可以按“工作”“个人”“开发测试”等用途管理分类，也可以把条目拖到对应分类中。分类名称要便于自己理解，不必分得过细。删除分类会连同分类内记录一起删除，整理时先确认分类中的内容。

顶部“搜索密码…”会匹配标题、用户名、网址和备注，多个关键词用空格分隔时，需要全部匹配，搜索范围跨所有分类。它不检索密码或 API 密钥正文，因此把用途写进标题和备注，比依赖记住密码片段更实用。

找到条目后，可以显示或隐藏密码，也可以复制用户名、密码等字段。复制敏感字段后，插件会安排约三十秒后清空剪贴板，但这依赖窗口仍在运行、剪贴板操作成功；不要据此假定其他软件没有读取过内容。用完及时锁定，避免把资料一直留在可见窗口中。

## 导入导出前，先看“包含密码”

左下角“导入导出”提供 JSON、CSV、TXT 等导出格式，以及相应的数据导入选项。首次迁入建议先用少量示例检查字段，核对标题、用户名、网址、分类和备注是否对应，再处理更多记录。

特别留意默认勾选的“包含密码”。保留勾选时，导出文件中会包含明文密码和 API 密钥，不能因为原记录在插件里受到保护，就认为导出文件也同样加密。不需要秘密字段时取消勾选；确需完整备份时，选择自己能妥善保护的位置，并确认文件内容与预期一致。

本次演示取消“包含密码”后完成了 JSON 导出，核对发现密码和 API 密钥字段均为“[已隐藏]”。这样的导出适合检查记录结构，不能用来恢复秘密字段，也不能替代完整备份。

JSON 导出得到的是 .json 文件，不是 SQLite 数据库。导入前也应核对插件支持的格式，不要直接拿 .db 文件替代。

## 用完锁定，理解保护范围

点击左下角“锁定”，界面会回到需要输入开屏密码的状态；插件也有无操作自动锁定逻辑。离开座位时主动锁定更直接，不必等待自动触发。

当前实现会对保存的密码和 API 密钥字段进行加密，标题、用户名、网址、备注等元数据没有同样的逐字段加密。因此可以把它理解为本地账号资料管理工具，并根据自己的资料敏感程度安排设备保护与备份。界面锁定也不等于立即擦除所有运行时内存数据。
