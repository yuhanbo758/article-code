桌面工具越用越多，真正麻烦的常常是找入口：有的程序藏在文件夹里，有的功能需要记住名字，Python 小程序又各自带着环境和依赖。三人聚智把这些入口放进一个主程序，日常先找工具，需要时再打开对应窗口。

![](https://xz.sanrenjz.com/image/%E8%A7%86%E9%A2%91%E5%B0%81%E9%9D%A2_16%E6%AF%949.png?imageSlim)

它包含“效率工具”和“py程序”两类入口。前者适合文本、文件、图片和数据处理，后者用于管理 Python 程序。两类工具共用主程序的搜索、设置和日志入口，但 Python 程序仍然需要合适的解释器与依赖。打开主程序，并不意味着必须先安装 Python。

这篇教程以 Windows 上的三人聚智 0.1.9 界面为例。示例使用独立演示数据；快捷键可以按自己的习惯调整。

## 先认识主界面，再安排常用入口

![](https://xz.sanrenjz.com/image/%E6%BC%94%E7%A4%BA%E6%88%AA%E5%9B%BE-%E4%B8%BB%E7%95%8C%E9%9D%A2.png?imageSlim)

启动后先看顶部搜索框，以及“效率工具”“py程序”两个切换按钮。卡片上可以查看工具名称、简介和版本，双击卡片打开工具；想先了解用途，可以查看详情。

主界面的搜索适合在当前列表里查找。需要在其他工作窗口中快速调用工具时，再使用全局快捷搜索。两者用途不同，刚开始不必记住全部插件名称，先熟悉几种常用工具即可。

顶部的“打开插件”用于添加已有程序，支持效率插件目录、Python 插件目录、单个 Python 文件和 ZIP。添加完成后，还要按实际需求打开或运行；导入本身不会自动执行业务任务。

## 设置里，先分清哪些操作需要保存

![](https://xz.sanrenjz.com/image/%E6%BC%94%E7%A4%BA%E6%88%AA%E5%9B%BE-%E8%AE%BE%E7%BD%AE.png?imageSlim)

点击“设置”，可以查看常规偏好、快捷键、超级面板、插件管理、Python 环境和数据导入等选项。

这里有一个容易忽略的区别：常规偏好和快捷键修改后，需要点击“保存设置”；插件、环境和数据导入中的具体操作按页面提示即时生效。切换页面时，留意待保存状态，确认保存成功后再关闭设置。

全局快捷搜索默认是 Alt+Space，钉住快捷键默认是 Ctrl+D。如果与其他软件冲突，可以在快捷键页重新录入并保存。超级面板的独立快捷键默认留空，本次演示专门设置为 Ctrl+Alt+P，它不是所有安装的默认值。Windows 还支持右键长按唤出超级面板，默认长按阈值为 350 毫秒，可在设置中调整。

插件管理聚合两类工具，也能查看隐藏项。是否在主界面显示，与是否随主程序启动是两项独立偏好。先把主界面整理到自己能看懂，再按需设置启动行为，通常更容易维护。

如果暂时只使用效率工具，可以先不配置 Python。准备运行 Python 程序时，再到环境页添加或选择解释器，并检查依赖。环境检查不会自动安装或切换解释器；缺少依赖时，应先查看变更计划，再决定是否安装。

## 用一个 JSON 示例走通完整调用

按 Alt+Space 打开快捷搜索，输入 json，选择“结构化数据工作台”，按回车打开。搜索支持空格分词；补充关键词，让覆盖更多关键词的结果排在前面；上下键用于选择，Esc 可以退出搜索窗口。

在工具输入区粘贴下面的独立示例：

```json
{"name":"三人聚智","tools":["效率工具","Python程序"],"demo":true}
```

选择 JSON 格式化，点击“执行”，结果区会把紧凑内容排成便于阅读的层级。再切到 JSON 校验并点击“执行”，本次示例的结果显示“JSON语法有效”。这一例子关注的是从宿主找到工具、打开工具并查看结果的完整路径。

![](https://xz.sanrenjz.com/image/%E6%BC%94%E7%A4%BA%E6%88%AA%E5%9B%BE-%E7%BB%93%E6%9E%9C.png?imageSlim)

JSON 格式化与校验只是一个使用示例。主程序还可以承载文件、图片、文本等其他工具，具体功能以已安装插件为准。遇到格式转换时，也要留意工具界面的限制说明；复杂数组、注释或特殊结构不一定能在不同格式间完整保留。

## 超级面板、日志与旧数据导入

快捷搜索主要解决“我知道要找什么”。超级面板则会结合选区或剪贴板里的内容给出相关操作，并提示当前内容来源。可以在设置中配置独立快捷键，或在 Windows 上启用右键长按入口。使用前先确认上下文，避免把无关的剪贴板内容当成输入。本次视频展示了这一入口的设置及调用逻辑，未展示实际面板处理过程。

主界面常显的“日志”入口，用于查看当前会话的近期记录。排查启动或处理问题时，可以按类型和插件筛选，再刷新或导出当前筛选结果。日志中的启动记录不能替代最终处理结果；仍应回到工具窗口检查实际输出。

如果从旧版效率工具或 Python 管理工具迁移，可以使用设置中的“数据导入”。先选择来源并查看预览，再执行导入。迁移会先备份、补充缺少的数据，保留新应用已有配置并提示冲突；不会把旧登录令牌、Cookie 或系统自启动设置一并搬过来，也不会在导入时运行插件。正式迁移前，仍建议核对来源目录和预览内容。

## 从少量常用工具开始

第一次使用，可以按这个顺序安排：先在主界面找到常用工具，再设置不冲突的快捷搜索键，最后根据需要配置超级面板和 Python 环境。每次只增加自己确实会用到的入口，比一次设置所有选项更容易掌握。

项目的正式发行入口是 [GitHub Releases](https://github.com/yuhanbo758/sanrenjz/releases)。下载时按自己的系统和架构选择对应安装包；具体发行版本以该页面实际内容为准。
