# stock_zh_a_spot_em：东方财富A股实时行情

获取沪深京A股行情，返回原有23列；超时/分页失败抛出 RuntimeError。

## 调用签名

```python
stock_zh_a_spot_em() -> pandas.DataFrame
```

## 参数

无参数。

## 返回结果

列：序号、代码、名称、最新价、涨跌幅、涨跌额、成交量、成交额、振幅、最高、最低、今开、昨收、量比、换手率、市盈率-动态、市净率、总市值、流通市值、涨速、5分钟涨跌、60日涨跌幅、年初至今涨跌幅。代码保留前导零，数值缺失为NaN。

## 异常与数据边界

网络、缺列、重复页或分页不完整均抛出异常，不把部分结果当成完整数据。成功空表仍保留约定列。数据日期由上游决定，周末返回缓存不代表实时交易日行情。
